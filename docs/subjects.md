# 📚 รายละเอียดวิชาที่เกี่ยวข้อง (Subject Mapping - Vanilla Version)

โปรเจกต์นี้พัฒนาด้วย HTML/CSS/JS โดยบูรณาการความรู้จาก 6 รายวิชาหลัก ดังนี้:

## 1. วิชาการสร้างสื่อดิจิตอล
**ส่วนที่เกี่ยวข้อง:** หน้า `index.html` (ศูนย์ ICT)
- การออกแบบหน้า Landing Page เพื่อการประชาสัมพันธ์
- การใช้ Visual Hierarchy เพื่อนำสายตาผู้ใช้งาน
- การเลือกใช้รูปภาพและสีที่สื่อถึงความทันสมัยของศูนย์เทคโนโลยี

## 2. วิชาระบบปฏิบัติการเครื่องแม่ข่าย
**ส่วนที่เกี่ยวข้อง:** หน้า `activities.html` (ข้อมูลเนื้อหา)
- การนำขั้นตอนการติดตั้งและการตั้งค่า Server (Windows/Linux) มาสรุปเป็นกิจกรรม
- การอธิบายการทำงานของ Active Directory และ DNS ในรูปแบบที่เข้าใจง่าย

## 3. วิชากิจกรรมในสถานประกอบการ 1
**ส่วนที่เกี่ยวข้อง:** หน้า `activities.html` (ข้อมูลเนื้อหา)
- การนำประสบการณ์จากการฝึกงานจริงมาเขียนเป็น Case Study
- การสรุปสิ่งที่ได้เรียนรู้ (Learning Outcomes) จากการปฏิบัติงานในบริษัท

## 4. การพัฒนาซอฟต์แวร์ด้วยเทคโนโลยี Front-End
**ส่วนที่เกี่ยวข้อง:** โครงสร้างโค้ดทั้งหมด
- การเขียน Semantic HTML เพื่อให้ Search Engine และ Browser เข้าใจโครงสร้าง
- การใช้ JavaScript (ES6) ในการสร้าง Dynamic Content (การ Render ข้อมูลกิจกรรมจาก Array)
- การจัดการ Event Listener สำหรับ Mobile Menu

## 5. การออกแบบส่วนติดต่อผู้ใช้ขั้นสูง (Advanced UI Design)
**ส่วนที่เกี่ยวข้อง:** CSS และ User Experience
- การทำ Responsive Design ด้วย CSS Grid และ Flexbox (Mobile-First)
- การเลือกโทนสี Dark Navy และ Accent Blue เพื่อให้ดู Professional และ Tech-oriented
- การออกแบบ Layout 16:9 แบบสลับฝั่งในหน้ากิจกรรมเพื่อให้เกิดความ Dynamic

## 6. เทคโนโลยีการจัดการฐานข้อมูล
**ส่วนที่เกี่ยวข้อง:** การจัดการข้อมูล (Data Handling)
- การเลียนแบบโครงสร้าง Database โดยการเก็บข้อมูลในรูปแบบ JSON-like Object ใน `activities.js`
- การใช้ JavaScript วนลูป (forEach) เพื่อดึงข้อมูลมาแสดงผลบนหน้าเว็บ (คล้ายกับหลักการ Fetch ข้อมูลจาก DB)
