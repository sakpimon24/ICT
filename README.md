# 🌐 โปรเจกต์พัฒนาเว็บไซต์ศูนย์การเรียนรู้ ICT ชุมชน เทศบาลเมืองเสาธงหิน
**(ICT Community Learning Center Project)**

เอกสารฉบับนี้เป็นเอกสารกำกับโครงการ (Project Documentation) สำหรับการพัฒนาเว็บไซต์ศูนย์การเรียนรู้ ICT ชุมชน เทศบาลเมืองเสาธงหิน ซึ่งเป็นส่วนหนึ่งของการศึกษาในรายวิชาคอมพิวเตอร์/เทคโนโลยีสารสนเทศ

## 📋 1. ข้อมูลทั่วไปของโปรเจกต์ (Project Overview)
โปรเจกต์นี้มีวัตถุประสงค์เพื่อสร้างเว็บไซต์ที่ทำหน้าที่เป็นศูนย์กลางข้อมูล (Information Portal) สำหรับประชาสัมพันธ์บริการและกิจกรรมของศูนย์ ICT ชุมชน โดยเน้นการนำเสนอที่ทันสมัย เข้าถึงง่าย และรองรับการใช้งานในทุกอุปกรณ์

- **ชื่อผู้พัฒนา:** นายศักดิ์พิมล ญาณโรจน์ (Sakpimon Yanarod)
- **สถานศึกษา:** วิทยาลัยเทคโนโลยีสยามบริหารธุรกิจ นนทบุรี
- **ระดับการศึกษา:** ประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.)

## 🎯 2. วัตถุประสงค์ของโครงการ (Project Objectives)
1. **เพื่อประยุกต์ใช้ความรู้:** นำทักษะการเขียนโปรแกรมเว็บด้วย HTML, CSS และ JavaScript มาสร้างผลงานที่ใช้งานได้จริง
2. **เพื่อสร้างสื่อประชาสัมพันธ์:** ให้ประชาชนในตำบลเสาธงหินรับทราบถึงบริการฟรี เช่น การใช้คอมพิวเตอร์ และอินเทอร์เน็ต
3. **เพื่อศึกษาการออกแบบ UX/UI:** ทดลองนำหลักการ Visual Hierarchy, Color Psychology และ Responsive Design มาใช้เพื่อให้เกิดประสบการณ์ที่ดีแก่ผู้ใช้งาน
4. **เพื่อฝึกฝนการจัดการข้อมูล:** ใช้ JavaScript ในการ Render ข้อมูลแบบ Dynamic เพื่อให้ง่ายต่อการแก้ไขและเพิ่มข้อมูลในอนาคต

## 🎨 3. แนวคิดการออกแบบ (Design Concept)
### 3.1 ระบบสี (Color Palette)
เลือกใช้ธีม **"Luxury White & Silver"** เพื่อสื่อถึงความทันสมัย ความสะอาด และความน่าเชื่อถือ:
- **Platinum White (#FFFFFF):** สีพื้นหลังหลัก สร้างความรู้สึกสะอาดตาและโปร่งสบาย
- **Silver Medium (#E9ECEF):** ใช้สำหรับแบ่งสัดส่วนและเส้นขอบ เพื่อให้ดูมีมิติแต่ไม่แข็งจนเกินไป
- **Charcoal/Silver Dark (#6C757D):** ใช้เป็นสีเน้น (Accent Color) และสีข้อความ เพื่อสร้าง Contrast ที่ชัดเจนและดูเป็นมืออาชีพ

### 3.2 หลักการ UX/UI ที่นำมาใช้
- **Visual Hierarchy:** จัดลำดับความสำคัญของเนื้อหาด้วยขนาดฟอนต์ (H1, H2, Body) และการใช้สีเน้น
- **Responsiveness:** ใช้แนวคิด Fluid Grid และ Media Queries แบ่งระดับหน้าจอเป็น 3 ระดับ (Desktop, Tablet, Mobile) เพื่อให้เนื้อหาไม่ล้นและอ่านง่ายในทุกอุปกรณ์
- **Glassmorphism:** ใช้การเบลอพื้นหลัง (Backdrop Filter) ในส่วนของ Navbar เพื่อเพิ่มความลึกและดูทันสมัย
- **Interaction Design:** เพิ่ม Micro-interactions เช่น การยกตัวของ Card (Hover Effect) เพื่อตอบสนองต่อผู้ใช้งาน

## 🛠️ 4. รายละเอียดทางเทคนิค (Technical Specifications)
### 4.1 Technology Stack
- **HTML5:** ใช้สำหรับสร้างโครงสร้างเว็บไซต์ตามมาตรฐาน Semantic HTML
- **CSS3:** ใช้ Custom Properties (Variables) ในการจัดการธีม และใช้ CSS Grid/Flexbox สำหรับการจัด Layout
- **Vanilla JavaScript (ES6+):** 
    - ระบบ Navbar Toggle สำหรับมือถือ
    - ระบบ Dynamic Rendering สำหรับการสร้างรายการกิจกรรมและ Gallery จาก Data Array
    - ระบบ Tooltip Interactive ในหน้า Design

### 4.2 โครงสร้างการทำงาน (Logic Flow)
1. **Data Layer:** เก็บข้อมูลกิจกรรมไว้ใน `js/activities.js` ในรูปแบบ Array of Objects
2. **Logic Layer:** `js/main.js` ทำหน้าที่ดึงข้อมูลจาก Data Layer มาวนลูปสร้าง HTML Elements
3. **Presentation Layer:** HTML และ CSS ทำหน้าที่แสดงผลตามโครงสร้างที่ถูกสร้างขึ้น

│   ├── main.js         # ควบคุมระบบการทำงานหลักและการ Render

└── public/             # ไฟล์ทรัพยากร
    └── images/
        ├── activities/ # รูปภาพประกอบกิจกรรม

เนื่องจากเป็น Static Website สามารถใช้งานได้ทันทีโดยไม่ต้องติดตั้ง Server:
1. ดาวน์โหลดโฟลเดอร์โปรเจกต์
2. เปิดไฟล์ `index.html` ด้วย Web Browser (Chrome, Edge หรือ Firefox)
